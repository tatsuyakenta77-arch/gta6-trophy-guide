An offline, open-source guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with cited sources, a three-step roadmap to the platinum, every missable trophy flagged, and a checklist that saves in the browser with export/import, kind filters and a spoiler mode. No network needed, no Rockstar artwork.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` from any static file server with `app/` at its root.
